# AI transparency and scope

The **intended runtime** combines local generative AI with NPC conversation, memory and dialogue integration; developer workflows also use AI assistance in research, writing and implementation.

This public repository ships **no AI model weights, generated voice assets, recorded character voices, private dialogue transcripts or AI-generated game files**. Source listings and descriptions are not a functioning AI mod.

Before any Nexus Mods upload of executable AI code or generated assets, disclose the actual models/tools and generated content under the platform's current policy. Source code, generated voices, media, documentation and third-party permissions must be assessed separately. Do not choose an inaccurate "AI Assisted" classification for components whose core code/assets were substantially generated by AI.

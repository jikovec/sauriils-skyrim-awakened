# Contributing references

For changes to mod references, include the original author page, exact version/file ID, relevant patch dependencies, save compatibility and verifiable source. New visual/gameplay variants must not be labeled compatible without a separate profile and tests.

Do not submit third-party mod archives, copies of game assets, AI voice data or credentials. By contributing original collection metadata/text you agree to its **CC0-1.0** dedication (to the extent you own those rights). A link to a mod never licenses the mod itself.

Disclose substantive generative-AI assistance when proposing new publication-ready files.

Record the assigned Issue, exact catalog and Core revisions, checks run and any private compatibility dependency using the [engineering orientation](docs/engineering/README.md).
